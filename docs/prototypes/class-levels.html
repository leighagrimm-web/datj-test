Showing class levels

Age gets a dancer in the door, but experience decides the class: a 9-year-old who has never tapped belongs in Tap I, not Tap I/II. Three ways to show that, each on the homepage class finder and on the schedule. Pick an age to see how each one behaves.

Option A

A level badge on every class

Every class gets a colored level and one line saying who it’s for. Nothing is hidden: families see the whole ladder and choose. Simplest to build and to keep up.

Option B

Ask about experience first

The finder asks one more question, “Has your dancer taken tap before?”, and only suggests classes that fit. The schedule marks the entry class “Start here” and says what comes before each of the others.

Option C

A level ladder per style

Each style shows its path from first class to advanced, with “Start here if new” on the right rung for the dancer’s age. Teaches families how the program builds, year to year. Takes the most space.
